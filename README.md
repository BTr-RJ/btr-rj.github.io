# BTr-RJ website

Static English-language project, support and privacy pages for BTr-RJ and RedBaron_Recomp. Built with HTML/CSS, without a framework, JavaScript, analytics or application backend.

## Hosting

GitHub Pages publishes the `docs` directory of the `main` branch. The custom domain is https://btr-recomps.com.br/; `docs/CNAME` binds it to this site. The domain was verified by the owner through the GitHub Pages DNS challenge. Hosting DNS records and HTTPS certificate issuance must also complete before the custom address is available. The original GitHub Pages address is https://btr-rj.github.io/.

## Pages

- `/`: developer and project overview
- `/redbaron/`: RedBaron_Recomp, downloads, requirements and online limitations
- `/support/`: support and privacy contact
- `/privacy/`: website and RedBaron_Recomp privacy policy

Public support/privacy contact: peixeurb21@gmail.com.

The logo in `docs/assets/mark.svg` is an original geometric B monogram authored for this website. `logo-128.png` is the same mark rasterized to the size required by Epic's brand form. It contains no original game artwork or third-party logo. PNG is retained for the submission format requirement.

This site contains no game content, generated game source, SDK/runtime binaries, saves or account credentials. The developer identity and project are independent of original rights holders and service vendors. A published website does not establish approval of Epic Account Services brand review.
