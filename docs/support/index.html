Report a RedBaron problem

Use RedBaron_Recomp GitHub Issues for reproducible bugs. Include:

  • The installed release version and whether this was a fresh installation or an update.
  • Windows version, CPU, GPU and relevant controller or audio hardware.
  • The mission or mode, exact steps and what you expected to happen.
  • The error text and a reviewed, redacted diagnostic log if needed.

GitHub Issues are public. For private details, contact the email above instead. Never send game files, DLCs, saves, EOS configuration, passwords or authentication tokens.

“Application Access Is Restricted”

Public Epic sign-in is currently restricted while the application's brand remains unapproved. Reinstalling the game will not by itself resolve that access restriction. Offline play remains available. Check the online status for the current limitation.

Privacy requests

Use the email above to ask about project-related data, request access or correction, withdraw consent for optional data you sent to support, or request deletion of data held for this project. Put “RedBaron privacy request” in the subject. Do not send a password, token or identity document.

See the privacy policy for the difference between local files, project data processed through EOS and your Epic account itself.
