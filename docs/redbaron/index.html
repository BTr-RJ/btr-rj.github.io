RedBaron_Recomp

Snoopy Flying Ace, rebuilt locally for Windows x64 from your original Xbox 360 game files.

Maintained by BTr-RJ, this independent fan project uses ReXGlue/ReXAuto to produce a native PC executable. The launcher handles extraction, code generation, compilation, settings and verified updates.

Download public testInstallation guideSource code

What you need

  • A Windows x64 PC and your own compatible original game files.
  • A new, empty folder for the first installation. The installer prepares the build tools it needs; the offline package bundles those tools.
  • Your own original DLC packages if you want to install supported DLCs.

No original game files, DLCs, generated game code or saves are supplied by this website.

Controls and video

Configure keyboard and controller mappings, windowed or borderless output, resolution, render scale and frame-rate targets in the launcher. Seven original game languages are available. Local split-screen supports two players.

FSR/CAS options and experimental temporal FSR/DLSS modes are available. Temporal artifacts and incomplete mode coverage remain known limitations. See the video documentation before choosing experimental settings.

Epic online access

Public Epic account access has not yet been approved. Accounts outside the developer organization can receive “Application Access Is Restricted” when signing in. Publishing the project or installing an update does not itself remove this service-side restriction.

The integration uses Epic Account Services for sign-in, friends and presence, and EOS for player identity, lobbies and peer-to-peer transport with relay fallback. Achievement and leaderboard integrations are implemented but still need broader gameplay validation.

Two-PC lobby and flight tests do not establish that every mode, invitation flow, full session, score submission or achievement synchronization works. Offline play remains available when authentication is unavailable. Read the online documentation and our privacy policy.

Testing and support

This is a public testing release. Report the version, hardware, game mode and steps needed to reproduce a problem through GitHub Issues. For private support or privacy requests, email peixeurb21@gmail.com.

Review and redact diagnostic logs before sharing. Do not upload original game files, DLCs, saves, EOS configuration, authentication tokens or passwords.
