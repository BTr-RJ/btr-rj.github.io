RedBaron_Recomp

Public testing release for Windows x64.

A native Windows x64 recompilation of Snoopy Flying Ace for Xbox 360, built with ReXGlue/ReXAuto. Includes a local-build launcher, configurable controls and modern video options.

The installer builds locally using files you supply. Original game files and DLCs are not distributed.
